# Over The Hill Mods

Fan-made mods for *Over The Hill*: First Person + VR, Wheel, Drive Assist, Proximity Voice and Big Lobby, with the OTH Setup app
that installs them, sets up wheels and microphones, and holds every setting.

**Download page: https://325c2.github.io/oth-mods/**, or grab the files from [Releases](https://github.com/325c2/oth-mods/releases/latest).

Unofficial, not affiliated with the makers of Over The Hill. Uses [BepInEx](https://github.com/BepInEx/BepInEx) (LGPL-2.1).
